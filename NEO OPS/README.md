# 🤖 NEO (Next Evolution Operator) Telegram Bot

A Matrix-inspired Telegram bot with AI responses and reality manipulation commands.

## 🌌 Features

- **Neo Mode** - Activate primary protocols
- **Override Reality** - Reality manipulation
- **Command Protocol Activate** - Destruction mode
- **This is a dream?** - Psychic sync
- **Offence** - Offensive modules
- **Defence** - Defence protocols

## 🚀 Quick Start

1. **Clone this repository**
2. **Install dependencies:** `pip install -r requirements.txt`
3. **Set your bot token** in `NEO_OPS.py`
4. **Run:** `python NEO_OPS.py`

## 📱 Commands

- `/start` - Show main menu
- `/help` - Show available commands
- Send any trigger phrase to get AI responses

## 🔧 Requirements

- Python 3.8+
- python-telegram-bot>=20.0
- Valid Telegram bot token
